# Focus List — Your Day, Organized

A responsive, dark futuristic productivity card inspired by the supplied reference image.

## Features
- Responsive layout for desktop and mobile
- Interactive task checkboxes
- Progress bar and percentage update automatically
- Accessible labels and keyboard focus styles
- Reduced-motion accessibility support
- No frameworks or dependencies

## Run locally
1. Extract the ZIP file.
2. Open the `focus-list-project` folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.

## Customize
- Change task names in `index.html`.
- Adjust colors and spacing in `style.css`.
- Add more `<li class="task">` items; the progress calculation automatically uses the total checkbox count.
